# インシデント対応（速報・確報・本人通知）

最終改定日: 2026-09-25（草案 v1。期限の数値は弁護士確認前の暫定値 — 下記「未確認事項」参照）

本ドキュメントは、個人情報の漏えい等またはサービスの重大な障害（決済関連の異常を含む）が
発生した際の初動から報告・通知までの手順を定める。実際の操作手順（コマンド）は
`docs/runbooks/RB-*.md` を参照し、本ドキュメントは**期限と担当**を定める。

## 1. インシデントの分類と初動

| レベル | 定義 | 初動 |
|---|---|---|
| SEV1 | 個人情報の漏えい・滅失・毀損が疑われる。または決済に関する資金移動の誤り（過払い・二重払いの拡大）が疑われる | 検知後 **1時間以内**に担当者（下記）へエスカレーション。`PAYMENTS_ENABLED` の縮退判断を開始（§17-5 のキルスイッチ条件に該当する場合は `docs/runbooks/RB-05-kill-switch.md`） |
| SEV2 | サービスの主要機能が停止・著しく劣化している（決済の新規開始不可等） | 検知後 **4時間以内**にエスカレーション |
| SEV3 | 軽微な不具合・単発の要対応（O-9）の増加 | 通常の運用対応（当日〜翌営業日） |

## 2. 個人情報の漏えい等（SEV1）の報告・通知期限

| 対象 | 期限 | 担当 |
|---|---|---|
| 個人情報保護委員会への速報 | 事案を知った後、**速やかに**（一般的な目安として概ね3〜5日以内。下記「未確認事項」） | 運営者代表（PO） |
| 個人情報保護委員会への確報 | 事案を知った日から **30日以内**（不正の目的をもって行われた行為による漏えい等の場合は **60日以内**。下記「未確認事項」） | 運営者代表（PO） |
| 本人への通知 | **遅滞なく**（法令上「速やかに」の定めがあり、確定の期日数値は下記「未確認事項」） | 運営者代表（PO）。通知先は保有する連絡手段（LINE のトーク等）に限られる場合があるため、`docs/runbooks/RB-07-incident-comms.md` の代替手段も検討する |

**未確認事項**: 上表の日数（速報3〜5日・確報30日/60日・本人通知「遅滞なく」）は、一般に公開
されている個人情報保護法・関連ガイドラインの記述に基づく暫定値であり、本タスク実施時点で
一次資料（個人情報保護委員会の公表資料）を取得できなかった（WebFetch が対象ページで 404、
WebSearch はセッションの利用上限に到達）。**確定版とする前に、一次資料の取得と弁護士確認を
行うこと**（`docs/concerns/task_021.md` に記録）。

## 3. 決済関連インシデントの対応

| 事象 | 判断 | 記録先 |
|---|---|---|
| 監査連鎖（`audit_log`）の不一致検知 | §17-5 のキルスイッチ条件に該当。`docs/runbooks/RB-05-kill-switch.md` の手順で `PAYMENTS_ENABLED` を停止するかを判断する | `audit_log` そのもの・`docs/HANDOFF.md` |
| 決済事業者からの異常な Webhook 増加・署名検証失敗の急増 | `docs/runbooks/RB-09-join-token-leak.md`・`RB-04-provider-suspension.md` を参照 | `webhook_delivery`・`docs/incident-response.md` の追記 |
| 参加者からの二重送金の自己申告が集中 | O-9 の要対応インボックスで個別確認。パターンが見られる場合は SEV2 として扱う | `payment_self_report`・`abuse_report` |

## 4. 連絡体制

| 役割 | 担当 | 連絡手段 |
|---|---|---|
| 運営者代表（PO・最終判断） | noritaka（NonTurn LLC） | 直接連絡 |
| 技術対応 | 当該タスクの実装・検証担当 | `docs/HANDOFF.md` 経由の引き継ぎ |

## 5. 事後対応

インシデント収束後、`docs/legal-forensics.md` の手順に従い、監査ログ・`webhook_delivery` 等の
証跡を確認する。再発防止策は `docs/concerns/<task_id>.md` またはプレモータム
（`docs/research/premortem-risks.md` / `docs/research/premortem-phase1b-2026-09-24.md`）へ
反映する。
