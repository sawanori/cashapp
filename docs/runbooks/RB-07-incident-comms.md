# RB-07: インシデント時の利用者・関係者への周知

## トリガー

- `docs/incident-response.md` の SEV1 / SEV2 に該当する事案が発生した。
- `PAYMENTS_ENABLED` を停止した（`RB-05-kill-switch.md`）。

## 手順

1. 影響範囲を特定する（全体か、特定の幹事・イベントか）。
2. 画面上の告知は `degraded` 状態（`src/components/StateView.tsx` の `ViewState` の 1 つ）を
   使い、「支払いを止めています」と「入金の記録は続いています」を分けて書く（§17-5・
   §8-3 の状態規約）。
3. 個人情報の漏えい等に該当する場合は `docs/incident-response.md` §2 の期限（本人への通知
   含む）に従う。通知手段は LINE のトーク等、既存の連絡経路に限られる（本アプリはメール・
   電話番号を保持しないため、他の通知手段を持たない。§7-5）。
4. 決済事業者との連携に影響がある場合は、当該事業者の窓口へも連絡する（Phase 2 以降）。

## 人間承認が必要な操作

- 利用者向け告知文の内容と送信タイミングの最終判断（運営者代表）。
- 個人情報保護委員会・本人への通知の実施（運営者代表。`docs/incident-response.md` の期限は
  弁護士確認前の暫定値であるため、実施前に確認すること）。

## 記録先

- 告知内容・送信日時は `docs/HANDOFF.md` に追記する。
- 画面上の `degraded` 表示の切り替えは、フィーチャーフラグ等の機構を Phase 1 では持たない
  ため、当該画面コンポーネントのデプロイで反映する（緊急時のホットフィックス相当）。
