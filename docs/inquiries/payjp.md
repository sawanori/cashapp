## 前提説明（質問文冒頭に付す）

私たちは、イベント幹事が参加者から会費・参加費を集める用途のLINEミニアプリを開発しています。幹事ご自身のPAY.JPアカウント（加盟店契約）へ参加者がカード決済で直接支払う構成を想定しており、当方（開発・運営元）は資金の受入れ・保管・引渡しには一切関与しません。以下をご教示いただけますでしょうか。

## 質問

### Q-PJ1 規約本文（個人間送金・立替精算の扱い）

貴社の加盟店規約（本文）において、友人・グループ内での会費徴収や立替金の精算のための決済利用は許容されますか。個人間送金や立替金の回収に該当するとして利用を制限される規定はありますか。

### Q-PJ2 非事業者の受け入れ可否

開業届を出していない個人が、継続的にイベントを主催し参加費を集金する目的で貴社の加盟店契約を申し込むことはできますか。必要書類（本人確認書類、開業届の代替となる確定申告書控え・個人事業税納付証明書等）を教えてください。

### Q-PJ3 手数料

決済手数料率と入金サイクル（入金頻度・締め日・最短入金日数）を教えてください。

### Q-PJ4 返金仕様

返金の実行方法（全額・一部）、1決済あたりの返金回数の制限、返金手数料の有無を教えてください。

### Q-PJ5 クレデンシャル預託の可否（Q-PP9相当）

加盟店の API シークレットキーを、加盟店ご本人ではなく開発・運営を受託した事業者（当方）が保管し、加盟店に代わってAPIを呼び出す構成は、貴社の規約上許容されますか。認証情報の第三者への開示・預託を禁止する規定がある場合、委託契約や権限分離（読み取り専用権限と決済実行権限の分離等）によって許容される余地はありますか。

### Q-PJ6 イベント参加費の対価性

懇親会・サークル活動等のイベント参加費の徴収は、貴社の取扱可能な商材（商品・権利・役務の対価）に該当しますか。

### Q-PJ7 同額多数決済と不正検知該当性

同一の加盟店アカウントで、同一金額（例: 4,000円・5,000円）の決済が短時間（数十分以内）に多数（10〜30件程度）発生する取引パターンは、貴社の不正検知モデルにおいてアクワイアラーからの加盟店契約解除等の対象になりえますか。イベント参加費徴収であることを疎明する資料（開催日時・会場・参加者名簿等）を事前に提出することで、このリスクを低減する方法はありますか。
