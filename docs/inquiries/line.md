## 前提説明（質問文冒頭に付す）

私たちは、イベント幹事が参加者リストを作成し、各参加者への会費請求と支払状況の管理を行うLINEミニアプリを開発しています。参加者は幹事名義の決済事業者アカウントへアプリ外（決済事業者ホスト画面）で直接支払い、当方（開発・運営元）は資金の受入れ・保管・引渡しには一切関与せず、決済結果の照会と名簿への反映のみを行います。以下をご教示いただけますでしょうか。

## 質問

### Q-LN1 禁止業種該当性

イベント幹事が参加者リストを作り、各参加者に会費の請求と支払状況の管理を行うLINEミニアプリを提供したいと考えています。この用途は、貴社ミニアプリポリシーの禁止業種「募金、寄附、クラウドファンディング等の資金調達」および禁止事項「チャリティまたは募金として寄付金を収集する目的の内容」に該当しますか。

### Q-LN2 アプリ内課金の要否

ポリシーの「LINEミニアプリ内で有料アイテム、有料サービス等を販売するためには…LINEアプリ内課金機能を利用しなければなりません」という条項について、現実世界の役務（飲食会の会費）の集金はこれに含まれますか。アプリ内課金が消耗型デジタルコンテンツ専用であることと矛盾しませんか。

### Q-LN3 集金仲介の審査評価

第三者（幹事）から第三者（参加者）への資金の集金を仲介するサービスは、認証審査基準の「法令における規制への抵触の有無」でどのように評価されますか。事前に確認すべき点はありますか。

### Q-LN4 催促のサービスメッセージ枠内送信

幹事から未払い参加者への催促を、サービスメッセージの「ユーザーの操作に対する確認や応答」の枠内で送ることは可能ですか（例: 参加者自身が「後で払う」を押した操作への応答として）。

### Q-LN5 未認証ミニアプリの利用者数上限

未認証ミニアプリに利用者数の上限はありますか。

### Q-LN6 利用料と通数カウント

LINEミニアプリのプラットフォーム利用料は無料ですか。サービスメッセージはLINE公式アカウントの月間メッセージ通数にカウントされますか。

### Q-LN7 shareTargetPickerの利用可否・申請要否

未認証のLINEミニアプリチャネルにおいて、招待リンクを友だちやグループへ共有するための `shareTargetPicker` API は利用可能ですか。利用にあたり事前の申請は必要ですか。
